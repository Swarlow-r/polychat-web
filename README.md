# PolyChat Landing Page (Static)

## 文件结构

- `index.html`：官网首页（含完整文案占位）
- `style.css`：营销站样式
- `404.html`：静态 404 页面
- `vercel.json`：Vercel 静态站最小配置

## 本地预览

直接双击 `index.html` 或使用任意静态服务器预览。

## 部署到 Vercel

1. 在 Vercel 导入该目录对应仓库。
2. Framework Preset 选择 `Other`。
3. Build Command 留空（纯静态）。
4. Output Directory 留空（根目录发布）。

## 部署到 Gitee Pages

1. 将本目录内容推送到 Gitee 仓库。
2. 在 Pages 中选择分支并发布。
3. 如使用项目子路径，资源已采用相对路径，可直接访问。
